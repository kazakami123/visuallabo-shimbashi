会員規約（入会金・解約・休会・再入会）

  1. 本規約は、当サロンとお客様との間のサービス利用契約に適用されます。

  3. 個別の契約書面と本規約の内容が異なる場合は、法令に反しない範囲で個別の契約書面を優先します。

第2条　入会・利用資格

  • 当サロンは男性専用です。ご利用者は男性に限ります。VIPルームはお一人でのご利用となり、お連れ様の同伴はできません。
  • 未成年者が契約する場合は、親権者等の法定代理人の書面または当サロン所定の方法による同意が必要です。
  • 健康状態、禁忌事項、施術内容および本規約を確認し、正確な情報を申告できる方に限ります。
  • 反社会的勢力に該当する方、その関係者、当サロンの運営や他のお客様に著しい支障を及ぼすおそれがある方はご利用いただけません。

第3条　契約の成立

  1. お客様が本規約、重要事項、プラン内容、支払総額および個人情報の取扱いを確認して申し込み、当サロンが承諾した時点で契約が成立します。
  2. 当サロンは、選択プラン、契約開始日・終了日、最低利用期間、初回支払額、最低利用期間中の支払総額、更新日および解約条件を、申込内容確認書または契約書面に個別に表示します。
  3. 特定商取引法上の特定継続的役務提供に該当する場合、当サロンは契約前に概要書面を、契約成立時に契約書面を交付します。ホームページの掲載だけをこれら法定書面の交付に代えるものではありません。
  4. 書面は原則として電子交付をご案内します。本人へ提供方法・保存方法等を説明し、必要な承諾と閲覧・保存の確認を行ったうえで、公式LINEから本人専用の契約内容を開き、保存できる方法で交付します。承諾しない方・電子交付を利用できない方には紙の書面で対応します。電子交付への承諾を強制せず、契約前の概要書面と契約成立時の契約書面を区別して交付します。法令上必要な承諾の控え等は別途書面でお渡しします。

第4条　サービスの性質と安全確認

  1. 当サロンは体型管理・コンディショニングを目的とするサービスを提供し、医療行為、診断または治療を行うものではありません。結果や体感には個人差があり、特定の効果を保証しません。
  2. ペースメーカー等の体内電子機器をご使用の方、妊娠中または妊娠の可能性がある方、治療中の疾患、金属インプラント、皮膚疾患その他の健康上の懸念がある方は、予約前に申告してください。安全上の理由により施術をお断りし、または医師への相談をお願いすることがあります。
  3. 体調の変化や既往歴等に変更があった場合、会員は速やかに当サロンへ申告するものとします。

第5条　料金・入会金

  1. 各プランの料金は料金ページおよび申込内容確認書に表示します。
  2. 入会金は16,500円です。初回体験当日に月額プランをご契約いただいた場合は0円、初回体験後7日以内にご契約いただいた場合は8,250円です。
  3. 体験当日の入会金無料特典を利用して退会した場合でも、入会金を遡って請求しません。
  4. 月額プランの利用に必須の商品購入はありません。任意の商品や追加サービスを希望する場合は、申込前に内容と税込金額を表示します。

第6条　月額会員の契約期間・自動更新

  1. BODY MAINTENANCEの初回最低利用期間は、月1回プランが3か月、月2回プランが2か月、月4回プランが1か月です。
  2. 温活メニューの初回最低利用期間は、月2回プランが3か月、月4回プランが2か月、月8回プランが1か月です。
  3. VIP月額プランは、月2回・月4回とも初回最低利用期間を1か月とします。
  4. 具体的な起算日と終了日は、契約時に申込内容確認書または契約書面へ記載します。
  5. 最低利用期間終了後は、会員または当サロンから終了の意思表示がない限り、1か月単位で自動更新されます。
  6. 入会日または各更新日から次回更新日前日までを1利用期間とします。入会日の応当日がない月は月末日を更新日とし、応当日が存在する次の月は元の入会日に戻ります。利用回数は利用期間ごとに付与し、カレンダー月では管理しません。

第7条　支払方法・決済日

  1. 月額会費は入会日に初回決済し、以後は入会日を基準に1か月ごと、登録済みクレジットカードへ自動課金します。入会日と同じ日がない月は、その月の末日を更新日とします。初回決済日と初回金額は申込時に表示します。
  2. 都度利用、体験、物販等は、当サロンが案内するクレジットカード、電子マネーまたは現金でお支払いいただきます。
  3. 決済不能となった場合、当サロンは既存の請求書によるお支払いを案内します。未払いが解消するまで、新たな予約またはサービス提供を停止する場合があります。
  4. 未払い分は既存の請求書を用いてお支払いいただきます。支払状況と残額を確認したうえで、お客様1名につき週1回を上限として、金額と既存のSquare請求書のお支払いリンクを公式LINEで再案内します。この再案内によって新たな請求や登録カードへの再決済を行うことはありません。支払済み・決済確認中・結果不明・支払内容に異議がある場合は自動再案内を停止して確認します。法令上の解除・返金・請求制限が優先します。
  5. 当サロンはカード番号を直接保有せず、決済事業者から決済結果等の必要情報を受領する場合があります。

第8条　利用期間ごとの利用回数・未利用分

  1. 月額プランの利用回数は、入会日または各更新日から次回更新日前日までの利用期間内に利用するものとします。
  2. 会員都合で利用しなかった回数は次の利用期間へ繰り越さず、換金・譲渡・返金を行いません。ただし、当サロン都合で予約済みのサービスを提供できなかった場合は、振替または相当額の返金を行います。
  3. 回数券およびVIP DEPOSITの有効期限・利用範囲は、各商品ページおよび個別の契約書面に表示します。

第9条　予約・変更・キャンセル

予約の変更、当日キャンセル、無断キャンセル、遅刻および当サロン都合による変更の取扱いは、予約・退会・キャンセル規程によります。キャンセル料等は、消費者契約法その他の法令に反しない範囲で適用します。

第10条　プラン変更

  1. アップグレードとは、同一メニュー・同一施術時間のまま、利用回数が多い月額プランへ変更することをいいます。各利用期間中いつでも店頭または公式LINEで申し出ることができ、当該利用期間について変更前後の月会費の差額全額をお支払いいただいた後、その日から適用します。差額の日割りは行いません。
  2. ダウングレードの受付期限による適用日は、各利用期間の開始日を1日目として15日目の23時59分までに店頭で受付を記録し、または公式LINEが申請メッセージを受信した場合は次回更新日、16日目以降の場合は次々回更新日とします。
  3. ダウングレードの適用日は、前項の受付期限による適用日と最低利用期間満了後の最初の更新日のうち、いずれか遅い日とします。最低利用期間中はダウングレードを適用しません。変更後の最低利用期間および精算額は、申込内容に応じて事前にお知らせします。
  4. 例として、9月14日から始まる利用期間では9月28日が15日目です。9月28日までにダウングレードを受け付けた場合は10月14日、9月29日以降に受け付けた場合は11月14日が受付期限による適用日となり、実際の適用日は、その日と最低利用期間満了後の最初の更新日のうち遅い日です。

第11条　休会

  1. 休会費は月額1,100円、休会期間は最長1年です。
  2. 休会の受付期限・最低利用期間は通常退会・ダウングレードと同じです。受付後、休会開始日、通常会費の最終請求日、休会費の請求日を個別に通知します。
  3. 休会中はいつでも復帰を申請できます。復帰する月額プランの支払い完了日を新しい利用期間・更新日の基準日とし、そのプランの最低利用期間を改めて適用します。最長1年の満了前に通知し、復帰しない場合は満了時に契約を終了して以後の請求を停止します。自動復帰は行いません。
  4. 休会からの復帰に再入会金はかかりません。休会中に退会を希望する場合も、第12条の手続が必要です。

第12条　通常退会

  1. 退会の申し出はいつでも可能です。店頭または公式LINEで受け付けます。
  2. 通常退会の受付期限による終了日は、各利用期間の開始日を1日目として15日目の23時59分までに店頭で受付を記録し、または公式LINEが申請メッセージを受信した場合は当該利用期間の末日（次回更新日前日）、16日目以降の場合は次の利用期間の末日（次々回更新日前日）とします。
  3. 通常退会の契約終了日は、前項の受付期限による終了日と最低利用期間満了日のうち、いずれか遅い日とします。最低利用期間中も退会申出を受け付けます。法令上のクーリングオフまたは中途解約の権利は、本条の受付期限や最低利用期間によって制限されません。
  4. 受付後、当サロンは受付日時、契約終了日および最終請求日を会員へ通知します。
  5. 利用期間の途中で契約が終了しても、その利用期間の月会費は日割り返金しません。ただし、法令上の解除・返金、当サロン都合による未提供分の返金を除きます。
  6. 退会後に再度入会する場合の入会金は16,500円です。休会からの復帰には入会金はかかりません。

第13条　最低利用期間中の中途解約

  1. 当サロンは、最低利用期間中であっても中途解約の申し出を受け付けます。
  2. 契約が特定継続的役務提供に該当する場合、サービス開始前の解約について請求できる額は法定上限2万円まで、開始後は提供済みサービスの対価に、2万円または契約残額の10％のいずれか低い額を加えた額までとし、既払額との差額を精算します。
  3. 前項の法定上限より会員に有利な個別条件がある場合は、その条件を適用します。法令の適用対象外となる契約についても、解約料は当サロンに生ずる平均的な損害を超えないものとします。

第14条　クーリングオフ

  1. 契約が特定継続的役務提供に該当する場合、会員は法定契約書面を受領した日から8日以内、書面または電子メールその他記録が残る電磁的方法により、理由を示さず契約を解除できます。
  2. クーリングオフは通知を発した時に効力を生じます。違約金、既に提供したサービスの対価その他の負担はなく、受領済み金員を速やかに返金します。
  3. 当サロンは、法令の適用対象外となる月額契約についても、原則として前2項と同等の8日間取消制度を適用します。
  4. 当サロンがクーリングオフについて事実と異なる説明や威迫を行い、会員が期間内に行使できなかった場合は、法令に従い期間経過後も行使できることがあります。

第15条　キャンペーン・特典

  1. キャンペーンの対象、期間、通常価格、割引額、最低利用期間、併用可否その他の適用条件は、申込前に明示します。
  2. 体験当日入会の入会金無料特典について、退会を理由とした入会金の遡及請求は行いません。
  3. 法令上のクーリングオフまたは中途解約の権利を、キャンペーン条件により制限しません。

第16条　サービスの中止・変更
