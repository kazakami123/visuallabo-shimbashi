# 表現コンプライアンス（薬機法・景表法）

正典は `compliance.yaml`（リポジトリ直下）。矛盾したら compliance.yaml を優先する。
この事業は VISUAL LABO（会員制体型管理サロン）。SOIREVE（下着ブランド群）とは別事業のため、
封印語・トーンを混同しない。

## 3層のワード分類
- **Tier A（封印）**: いかなる媒体でも使わない。例:「必ず痩せる」「治る」「治療」「改善保証」。
  → hook (`compliance-guard.sh`) が書き込み時に機械的にブロックする。リストは `.claude/compliance/blocklist.txt`。
- **Tier B（教材限定）**: スタッフ教材・社内資料のみ。顧客向け公開物には出さない。
- **Tier C（条件付き可）**: 断定を避ける・体験談として書く等の条件付きで可（インディバ比較表現など）。

## 基本ルール
- 医薬品的な効能効果を断定しない（「治る」「必ず痩せる」等の言い切りをしない）。
- 効果に触れたら「※効果・感じ方には個人差があります」を近くに置く。
- 事実と体感を区別する。ビフォーアフター表現は景表法の裏付けルールに従う。
- 機械関連ページには禁忌注記（ペースメーカー・妊娠中・金属インプラント等）を必ず残す。
- GLP-1 等の医薬品名（Rybelsus / Mounjaro 等）は知識型コンテンツのみ。効能記載は禁止。

## コラムの自動生成（2026-10-19 導入）

`drafts/*.md` → `learn-<slug>.html` の変換パイプラインがある。手順は `COLUMN-HOWTO.md`。

- **自動で公開はしない。** GitHub Actions は Pull Request を作るところで止まる。
  マージは人が判断する。月30本を無審査で出さない
- 変換の前に `tools/check-compliance.py` が封印語と絵文字を機械チェックする。
  1件でも当たると変換が止まる
- **サイトに載せるのは月4〜8本まで。** Googleの大量生成コンテンツのポリシーに当たるため、
  noteの30本をそのまま全部サイトに載せない
- **noteより先にサイトへ出す。** 逆だと重複コンテンツでnote側が正規版になる
- `tools/column-template.html` は既存コラムから機械抽出したもの。手で編集しない

## 「向いていない方」の書き方（2026-10-22 オーナー確定）

**向いていないのは、いわゆる「メンズエステ」を期待して来店される方。**
施術スタッフが女性であるため誤解が生じやすく、曖昧にするとスタッフを守れない。

掲載先は3つ。**内容を変えるときは3つとも同時に直す。**

| ファイル | 場所 |
|---|---|
| `flow.html` | 「向いている方・向いていない方」ブロック（予約前に読まれる位置） |
| `faq.html` | 「どんな人に向いていますか？向いていない方はいますか？」 |
| `terms.html` | 第17条 禁止事項（実効性のため規約にも入れてある） |

### 書き方のルール

- **当サロンが何をする場所かを先に言う**（高周波とHYPER EMSで体型を管理する施術）。
  そのうえで「施術以外のお時間の提供は行っておりません」と事実だけを書く
- **他業種を名指しで貶めない。** 「風俗」など直接的な語は使わない。
  「いわゆる『メンズエステ』をお探しの方」までにとどめる
- **境界は具体的に書く。** 身体的な接触／連絡先の交換／業務時間外のお誘い。
  抽象的な「迷惑行為」だけだと現場で止められない
- **対応も書く。** 「施術を中止し、以後のご予約をお断りすることがあります」
- 施術スタッフが女性であることは `faq.html` に既出。隠さない
