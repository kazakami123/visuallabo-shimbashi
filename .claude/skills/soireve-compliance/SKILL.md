# SOIREVE / VISUAL LABO 表現コンプライアンス

## 適用

まどかの制作物すべて（LP・SNS・商品ページ・広告・スタッフ資料）。
薬機法・景表法がベース。「やり方」はこのスキルで共通、「具体語彙」は事業ごとに別。

## 事業の分離（最優先）

- VISUAL LABO … 会員制体型管理サロン事業。
- SOIREVE … 下着ブランド群（M'DREA / meguru / FROLA / PINK PINK）。

両者は別事業。制作対象がどちらの事業のどのブランドかを先に確定し、
その事業のリポジトリにある compliance.yaml / blocklist.txt だけを正典として使う。
片方の封印語・トーンをもう片方に流用しない。

## 3層のワード分類

- Tier A（封印）: いかなる媒体でも使用禁止。→ hookが書き込み時に機械ブロックする。
- Tier B（教材限定）: スタッフ教材・社内資料のみ。顧客向け公開物には出さない。
- Tier C（条件付き可）: 断定回避・体験談化などの条件付きで可。

## 基本ルール

- 医薬品的効能を断定しない（「治る」「必ず痩せる」等の言い切り禁止）。
- 事実と体感を区別する。ビフォーアフターは景表法の裏付けルールに従う。
- GLP-1医薬品名（Rybelsus / Mounjaro 等）は知識型コンテンツのみ・効能記載禁止。

## 制作フロー

1. 対象事業・ブランドを確定 → その compliance.yaml / blocklist.txt を読む。
2. 執筆。Tier A語は一切使わない。Tier B/Cは条件を守る。
3. 公開前は compliance-reviewer サブエージェント（または /publish-check）で審査。
   Tier A検出は1件でも「公開不可」。該当は原文引用で具体的に示す。

## 正典

- 具体語彙：各リポジトリの compliance.yaml（blocklist.txt はそのTier Aミラー）。
- 迷ったら厳しい側に倒す。推測で「たぶん大丈夫」と言わない。
