# VISUAL LABO デザインシステム参照

## 適用

このリポジトリで *.html や style.css を新規作成・編集する作業全般（TOP・下層ページ・セクション追加・コンポーネント修正）。

## 手順

1. 作業前に必ずリポジトリ直下の `DESIGN.md` を読む。色トークン（`--bg`/`--gold`/`--paper`等）・フォントスタック・ボタンやカードの作り方・Do's and Don'ts・レスポンシブのブレークポイントがまとまっている。
2. `CLAUDE.md` の作業ルール（絵文字禁止、モバイル375〜430px確認必須、旧価格・旧メニュー名の禁止等）も合わせて確認する。DESIGN.mdは見た目のルール、CLAUDE.mdは運用・データの正典という役割分担。
3. 実装後は CLAUDE.md の検証ルールに従う（ローカルサーバー＋スクリーンショット、タグ整合、CSS波括弧数、モバイル幅での崩れ確認）。

## 正典

- 見た目（色・フォント・コンポーネント・レイアウト）: `DESIGN.md`
- 運用・価格・表現ルール・作業手順: `CLAUDE.md`
- 表現コンプライアンス: `soireve-compliance` スキル（別途発火）

DESIGN.mdとCLAUDE.mdの内容がずれていたら、まずユーザーに確認する（どちらが正か推測しない）。
