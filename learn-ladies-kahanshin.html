重力と、ポンプの話

体の水分は、心臓から下に向かうときは重力に助けられますが、戻るときは重力に逆らうことになります。下半身は、いちばん遠くていちばん下にあります。

戻りを支えているのが、ふくらはぎなどの筋肉です。筋肉が縮んだりゆるんだりするたびに、血管やリンパ管を外から押して、中身を上へ送り出しているといわれます。「第二の心臓」と呼ばれるのはこのためです。

つまり、動かない時間が長いほど、ポンプが止まっていることになります。デスクワークで座り続ける、立ち仕事で同じ姿勢が続く。どちらも、ふくらはぎが動いていないという点では同じです。

女性のほうが感じやすいといわれる背景

一般に、次のような要因が重なるためといわれます。

  • 筋肉量が少ない傾向がある … ポンプのはたらきが弱くなりやすい
  • 体が冷えやすい … 温度が下がると巡りが鈍りやすいといわれます
  • 靴 … ヒールや、足指が動かしにくい靴は、ふくらはぎを使いにくくします
  • 衣服の締めつけ … 下着や衣類で強く締めると、戻りの妨げになることがあります
  • ホルモンの周期による体調の変化 … 時期によって感じ方が変わることがあります

どれも「体質」というより、生活の中にある要因です。だから、手の入れようがあります。

「水を控える」は逆向きです

よくある誤解です。水分を減らしても、重さが軽くなるわけではないといわれます。足りないと、体はむしろためこむ方向に働くとされています。控えるのではなく、こまめに分けてとるほうが理にかなっています。

ふくらはぎ・足首

いちばん先に重さが出て、いちばん手を入れやすい場所です。ポンプそのものだからです。

できることは、動かすこと。座ったままでも、かかとを上げ下げするだけで、ふくらはぎは動きます。1時間に1回、10回ずつでも違うといわれます。

足首が硬いと、ふくらはぎが十分に縮みません。足首を回す。足指をグーパーする。 地味ですが、ここが動かないとポンプは効きません。

太もも（前・内・裏・外）

太ももは大きな筋肉の集まりですが、日常で使う場所と、使わない場所の差が大きいのが特徴です。

  • 前もも … 歩く・立つで使うので、張りやすい側です
  • 裏もも（ハムストリング） … 座っている時間が長いと、縮んだまま固まりやすいといわれます
  • 内もも（内転筋） … 脚を閉じる動きで使いますが、日常ではあまり使いません
  • 外もも … 重心のクセが出やすい場所です。片脚に体重をかけるクセがあると、片側だけ張ることがあります

自分で動かそうとすると、使えている場所ばかり使ってしまうのが難しいところです。前ももは鍛えられるのに裏ももは変わらない、というのはよくある話です。

ヒップ

座っている時間が長いほど、使われないまま押しつぶされている時間が長い場所です。

大臀筋は体の中でも大きな筋肉で、歩く・立ち上がるといった動作の土台になります。ここが働いていないと、その分を腰や前ももが肩代わりすることになり、腰の張りにつながることもあるといわれます。

順番があります

いきなり強く動かすより、順番があります。

1. 温める。 冷えた状態では、筋肉も血管も動きにくいといわれます。湯船につかる、温かいものを飲む。できる範囲で構いません。

2. 動かす。 温まってから動かすほうが、動きやすくなります。歩く、階段を使う、かかとを上げ下げする。

3. 戻りを助ける姿勢をとる。 寝るときに脚を少し高くする。これだけでも、戻りを重力に手伝ってもらえます。

4. 締めつけを見直す。 強く締める下着や衣類を、長時間つけたままにしない。

毎日は続かない、という方へ

ここまで読んで「どれもできていない」と思われたなら、それが普通です。続かないことを前提に組んだほうがいいと考えています。

当サロンでやっているのは、この「温める」と「動かす」を、横になったまま外から行うことです。高周波で体の内側から温めて、仕上げに HYPER EMS で筋肉を動かします。自分で力を入れる必要はありません。

運動の代わりではありません。時間が取れない方のための、もうひとつの選択肢だと思っていただければと思います。
